# 🎨 Variáveis CSS Dinâmicas com JavaScript / Dynamic CSS Variables with JS

[Português] Uma aplicação interativa que permite alterar as propriedades visuais de uma imagem (espaçamento, desfoque e cor de fundo) em tempo real, utilizando apenas JavaScript puro para manipular variáveis CSS.
[English] An interactive application that allows you to change the visual properties of an image (spacing, blur, and background color) in real-time, using pure JavaScript to manipulate CSS variables.

---

## 🇧🇷 Português

### 🚀 Tecnologias Utilizadas
* **HTML5:** Utilização de inputs do tipo `range` (sliders) e `color`, além de atributos customizados com `data-*`.
* **CSS3:** Declaração de variáveis no escopo global (`:root`) e aplicação dinâmica utilizando a função `var()`.
* **JavaScript:** Captura de eventos contínuos (`mousemove` e `change`), leitura de atributos do HTML via `dataset` e atualização direta do CSS via `style.setProperty()`.

### 🧠 O que aprendi
Neste projeto, o foco foi entender como o JavaScript pode se comunicar de forma eficiente com o CSS.
* Aprendi a utilizar atributos customizados (`data-sizing`) no HTML para passar informações (como a unidade "px") para o JavaScript.
* Compreendi que atualizar variáveis CSS no `:root` é uma técnica muito mais limpa e performática do que alterar estilos inline elemento por elemento.

### ⚙️ Como executar
1. Faça o clone deste repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador.
3. Utilize os controles no topo da página para ver a imagem se atualizando em tempo real!

## 🇺🇸 English

### 🚀 Technologies Used
* **HTML5:** Use of `range` (sliders) and `color` inputs, along with custom attributes using `data-*`.
* **CSS3:** Declaring variables in the global scope (`:root`) and dynamically applying them using the `var()` function.
* **JavaScript:** Capturing continuous events (`mousemove` and `change`), reading HTML attributes via `dataset`, and directly updating CSS via `style.setProperty()`.

### 🧠 What I Learned
In this project, the focus was understanding how JavaScript can efficiently communicate with CSS.
* I learned how to use custom attributes (`data-sizing`) in HTML to pass information (like the "px" unit) to JavaScript.
* I realized that updating CSS variables in `:root` is a much cleaner and more performant technique than changing inline styles element by element.

### ⚙️ How to Run
1. Clone this repository or download the files.
2. Open the `index.html` file in any browser.
3. Use the controls at the top of the page to see the image update in real-time!
